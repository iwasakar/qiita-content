## 環境
Flutter　2.10.5
Android Studio Bumblebee | 2021.1.1 Patch 2
ちょっと古い環境のようであまり記事がなかった。

## エラー

```shell
flutter doctor --android-licenses

This tool requires JDK 17 or later. Your version was detected as 11.0.11.
To override this check, set SKIP_JDK_VERSION_CHECK.
```

## 選択肢の整理
エラーメッセージを見る限り、取れる手は3つ。

1. ローカルにJDK 17を入れる
2. `SKIP_JDK_VERSION_CHECK` を設定してチェック自体を回避する
3. Android Studio / Flutterごと新しくする

2はチェックを黙らせるだけで原因が残る。3は古い環境のプロジェクトなので影響範囲が読めない。1ならJDKの追加とPATHの切り替えだけで済み、ダメでも戻しやすいので1にしました。

## 対応
ローカルのJDKを17に更新する
Android Studio側はJDK11で動く模様。
つまり、flutter doctorのライセンスチェックが要求するJDKと、Android Studio（IDE）が使うJDKは別物。こちらを17にしてもIDE側は今まで通り動きます。
```shell
brew install openjdk@17

~/.zshrcに下記追加
export JAVA_HOME=/usr/local/opt/openjdk@17
export PATH=$JAVA_HOME/bin:$PATH

source ~/.zshrc
```

## 結果
無事ライセンス認証フローに移れば成功です。

## 余談
環境をひと通り新しくしたいです。
今回のように、古い環境を維持するコストが回避策の調査時間としてじわじわ現れ始めているので、更新の優先度は上げたいところ。
Android開発やFlutter開発を積極的に行っていく。
